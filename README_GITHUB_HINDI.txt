GitHub Cloud Build:
1. GitHub par repository banayein.
2. Is folder ke andar ki saari files upload karein.
3. .github/workflows/build-windows.yml bhi zaroor upload ho.
4. Repository > Actions > Build Vyapar Counter Windows Setup > Run workflow.
5. Build complete hone par workflow run kholen > Artifacts > Vyapar-Counter-Windows-Setup download karein.
6. ZIP extract karke Setup.exe install karein.
