VYAPAR COUNTER 2.0 - DATA LOCATION + STANDALONE DATABASE

Is version mein better-sqlite3/native module hata diya gaya hai. Data selected Windows folder mein vyapar-data.json ke roop mein safe rahega.
Target PC par Node.js/npm ki zarurat nahi hogi jab final Setup.exe ban chuka ho.

DATA LOCATION:
Settings > Data Location > Data Folder चुनें.
Purana data automatically delete nahi hota. Naya folder choose karne par current data copy hota hai.
Agar folder mein pehle se Vyapar data ho to Existing/Replace/Cancel ka option aata hai.

BACKUP:
Documents > Vyapar Counter Backups mein automatic daily backup banta hai. Purane backups automatic delete nahi hote.

BUILD:
Setup banane wale PC par Node.js + internet chahiye. BUILD_FINAL_SETUP.bat double-click karein.
Final user PC par sirf generated Setup.exe install karna hai; Node/npm/Visual Studio ki zarurat nahi.
