⚙️ Company Settings

Windows Database

Windows desktop build में यह app SQLite database के साथ चलता है। Automatic Daily Backup ON — हर दिन software खुलने पर एक backup अपने-आप बनेगा और पुराने automatic backups कभी अपने-आप delete नहीं होंगे।

📂 Data Location

आप अपने हिसाब से कोई भी Windows folder चुन सकते हैं। आगे का नया data उसी folder में vyapar.db के रूप में सेव होगा। Folder बदलने पर मौजूदा data सुरक्षित रूप से नए folder में copy किया जाएगा और वहीं से आगे save होगा।
